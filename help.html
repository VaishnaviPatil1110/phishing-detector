Help & User Guide

🔍 How to Use

  • Go to Dashboard
  • Enter a URL
  • Click "Analyze URL"
  • Review the risk score

🛡️ Safety Tips

  • Do not click unknown links
  • Never share passwords
  • Always verify HTTPS security
  • Beware of urgent requests

⚠️ Understanding Results

  • Phishing: Dangerous or fake
  • Safe: Appears legitimate
  • Risk Score: Higher means more dangerous

🌐 URL Detection

The system checks URL structure, SSL certificates, DNS information, and WHOIS records to identify suspicious websites.

🔧 Troubleshooting

  • Ensure backend server is running
  • Verify API is active on port 5000
  • Check internet connection
  • Refresh the page if errors occur
