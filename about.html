About This Project

This phishing detection system analyzes URLs and email content using machine learning concepts and rule-based techniques.

It checks multiple factors such as URL structure, SSL security, suspicious keywords, and links to determine whether a website or email is safe or phishing.

The goal of this project is to improve user awareness and help prevent cyber attacks through intelligent threat detection.

🌐 URL Analysis

Detects suspicious domains, fake login pages, and malicious URL patterns.

🛡️ Security Checks

Verifies SSL certificates, WHOIS data, and DNS records for added protection.
